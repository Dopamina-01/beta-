# DOPAMINA

Aplicación web para registrar, almacenar y analizar la producción diaria de una empresa con turnos Día y Noche.

## Qué incluye

- Dashboard para registrar producción diaria
- Historial editable con búsqueda y filtros
- Sección de estadísticas y gráficos básicos
- Exportación a CSV, Excel y PDF
- Configuración de empresa, metas y respaldo de datos

## Cómo usarlo

1. Abre el archivo index.html en un navegador.
2. Registra los valores de producción de los turnos Día y Noche.
3. Usa las otras secciones para revisar el historial, estadísticas y exportar reportes.

## Persistencia

Los registros se almacenan en el navegador mediante localStorage, por lo que permanecen disponibles aunque cierres la aplicación.
