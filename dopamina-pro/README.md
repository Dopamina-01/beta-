# DOPAMINA PRO

Versión alternativa de la aplicación de control de producción con un nombre distinto y una identidad visual renovada.

## Qué incluye

- Dashboard para registrar producción diaria
- Historial editable con filtros y búsqueda
- Estadísticas y gráficos básicos
- Exportación a CSV, Excel y PDF
- Configuración de empresa, metas y respaldo de datos

## Uso

1. Abre el archivo index.html dentro de esta carpeta en tu navegador.
2. Registra la producción del turno Día y Noche.
3. Usa las otras secciones para visualizar reportes y exportar datos.
